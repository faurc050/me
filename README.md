# Python Dungeon RPG Prototype

Version 1.0.2

A cleaner, more stable 2D dungeon RPG prototype built with Python and Pygame.

## Features
- WASD movement
- mouse aim
- left-click attacks
- dodge roll
- random room dungeon
- enemies, gold, upgrades, boss fight
- generated sounds
- menu + pause menu + game over + victory flow
- music toggle
- full 360-degree character aiming and weapon rotation

## Run on Windows
1. Open PowerShell in the project folder, or just double-click `run_game.bat`.
2. Create a venv if desired:
   python -m venv venv
   .\venv\Scripts\Activate.ps1
3. Install dependencies:
   pip install -r requirements.txt
4. Start the game:
   python main.py
   or
   .\run_game.bat

## Controls
- Move: W A S D
- Aim: Mouse
- Attack: Left click
- Dodge: Space
- Upgrade choices: 1, 2, 3
- Enter door: E
- Pause: Esc
- Toggle music: M
- Restart: Enter
